# La Liga Match Outcome Prediction & Season Simulation

A machine learning project that predicts La Liga match outcomes and uses Monte Carlo simulation to estimate season performance and title probabilities.

## Project Overview

Using historical La Liga match data from 1995–2025, this project explores whether team form, goal differences, and home/away performance can predict match outcomes.

## Methods

- Exploratory data analysis (EDA)
- Feature engineering: recent team form, goal difference, and venue performance
- Classification models: Logistic Regression and Random Forest
- Monte Carlo simulation for full-season forecasting

## Tools

Python, pandas, NumPy, scikit-learn, Matplotlib, and Seaborn
